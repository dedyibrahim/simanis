# SIMANIS Word 0.6.0 Preview

Fitur garis bekerja langsung tanpa desktop berlisensi atau server aktivasi. Tombol Penghadap / Transaksi PPAT memakai helper SIMANIS Word Data dan login akun SIMANIS. Alamat API HTTPS dan CA internal dapat diatur dari dialog login.

Panduan lengkap: [SIMANIS-DATA.md](SIMANIS-DATA.md). Build: `python build_simanis_word.py` dari folder sigandi. Kebijakan macro Office tidak diubah. ID macro, shape, bookmark, dan preferensi lama dipertahankan agar dokumen sebelumnya tetap kompatibel.
